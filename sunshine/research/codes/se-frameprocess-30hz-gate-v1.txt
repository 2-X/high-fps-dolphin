$SE frame-process 30Hz gate v1 [kris]
* Normalizes EVERY repeating sound effect at high fps: FLUDD hover putter,
* spray hiss, Gooper Blooper tentacle squeak, Noki urn rope creak, etc.
* Mechanism: actors request repeating SEs every move tick; the audible
* retrigger cadence is set by JAudio's per-rendered-frame SE processing pair
* (JAIBasic::checkNextFrameSe USA 0x80305204 releases stale continuous SEs +
* starts pending ones + ticks one-shot lifetimes; sendPlayingSeCommand USA
* 0x80305958 resets refreshed sounds and advances per-sound pitch counters).
* At 120fps the pair runs 4x too often -> all repeating SEs retrigger 4x fast.
* Gate both to 1 rendered frame in FPS/30 (here 4). The send hook owns the
* shared counter (0x800016E8); the check hook tests counter+1 WITHOUT storing
* (it runs first each frame and is conditionally skipped during init), so both
* pass on exactly the same frames. Early blr before the prologue (orig insn is
* mflr r0 for both, vtable-verified entries, no derived overrides in the dol).
* SUPERSEDES cogwheel-creak-gate-v1.txt (request-side gating starves the
* keep-alive window -> 60/sec chop). Generated by fpspatch.py se_frame_gate();
* divisor: 120fps=4 (andi.), 180fps=6 (exact mod), 240fps=8.
