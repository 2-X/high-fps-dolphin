Tank Controls v2 (rate-limited steering, tuned for 360fps bundle)
GMSE01 (US). Supersedes tank-controls-v1 (remove v1 when enabling v2).

v1 problem (user-confirmed at 360fps): downstream yaw chase is
  mFaceAngle.y = mIntendedYaw - IConverge(diff, 0, rotSp, rotSp)
i.e. a CLAMPED FIXED STEP per sim frame (rotSp ~0x600-0x800 while
running). v1 set intendedYaw = face + stickOffset each frame, so any
deflection > ~rotSp saturated the clamp -> max turn step EVERY frame,
and at 360fps that is 6x the per-second rate -> spin-in-circles on
slight side deflection. Scaling the stick angle alone can't fix it
(mid deflections still saturate the clamp), so v2 emits the per-frame
turn increment itself.

Hook: C2 @ 80251ddc (replaces the final `add r0,r3,r0` before
`sth r0,0x90(r31)` in TMario::checkController). Live regs:
r3 = matan stick angle (forward = 0x8000), r30 = dizzy yawJitter,
r31 = TMario* this. r0/r4 free (r4 held gpCamera, dead after patch).

Logic (theta = stick angle - 0x8000, signed s16, 0 = dead ahead):
  if |theta| >= 0x6000 (rear ~90deg cone): offset = theta
      -> full target flip; triggers the vanilla skid/turnaround state
         (its trigger threshold is 0x471C) and IConverge's own clamp
         paces the rotation. Back = instant turnaround, preserved.
  else: offset = clamp(theta >> 6, +/-0xC0)
      -> proportional steering: 22deg deflection ~0.35 rev/s,
         45deg ~0.7 rev/s, capped ~1.05 rev/s at 360fps.
  mIntendedYaw = mFaceAngle.y + offset + yawJitter

TUNING KNOBS (for feel iteration, all in the block):
  srawi shift 6  (word 0x7C803670) -> steering gain; 5 = twice as fast
  cap 0xC0       (words 0x380000C0/0x2C0000C0 and FF40 pair) -> max turn rate
  cone 0x6000    (words 0x2C046000/0x2C04A000) -> turnaround threshold
NOTE: rates are per-sim-frame, so feel scales with G. Tuned for G=6
(360fps). At other G, scale shift/cap accordingly; folding this into
fpspatch.py as a G-parameterized emitter is the clean follow-up.
