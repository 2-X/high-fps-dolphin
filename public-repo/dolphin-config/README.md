# Ready-to-use Dolphin settings

Copy these three files into Dolphin's user folder and everything is configured
for you. See [Step 3 of the setup guide](../docs/SETUP-WINDOWS.md#step-3--copy-in-the-config-files).

| File | Goes in | What it does |
|---|---|---|
| `Dolphin.ini` | `Config\` | Turns on cheats, sets the Vulkan graphics backend and correct audio options |
| `GFX.ini` | `Config\` | Graphics settings tuned for high FPS + shows the FPS counter |
| `GameSettings\GMSE01.ini` | `GameSettings\` | The cheat codes themselves, the memory override, and the FPS speed setting |

`GMSE01.ini` is the one you'll edit if you want to switch between 120 / 180 / 240
FPS — see the setup guide. The other two you can copy once and forget.

> These are tuned for Windows. If you already had Dolphin set up, back up your own
> versions of these files before overwriting them.
